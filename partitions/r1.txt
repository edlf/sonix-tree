# Partition table of the HiBy R1 (SPI NAND, 128 MiB), written into the
# -withparts U-Boot images at 0x5800 by partitions/mkparttable.py.
#
# The SPL and U-Boot read it: "nand", the number of entries, then per entry
# name[32], size, offset, mask_flags, manager_mode (little endian). The
# offsets and sizes are the R1's stock ones; the recovery root fs is called
# "rootfs2", as before firmware 2.0 and on the R3 Pro II. Firmware 2.0 wrote
# a table that calls it "rootfs" again (rootfs twice), which HiBy's own OTA
# scripts cannot look up; the recovery's "Install fastboot" renames it back
# (recovery/src/parttable.h). The bootloader and fastboot accept either.
#
# name      offset      size        manager  mask_flags
uboot       0x00000000  0x00080000  mtd      0
kernel      0x00080000  0x00500000  mtd      0
rootfs      0x00580000  0x02d00000  mtd      0
kernel2     0x03280000  0x00500000  mtd      0
rootfs2     0x03780000  0x01800000  mtd      0
ota         0x04f80000  0x00080000  mtd      0
userdata    0x05000000  0x03000000  ubi      0
